# Rift Runners

A free browser arena prototype hosted on GitHub Pages.

## Current features
- Home menu with trophies, wins, best record, and rank.
- Win a bot match: +10 trophies. Lose: -7 trophies, with a minimum of 0.
- Trophy Road: every 100 trophies permanently unlocks a cosmetic skin. Unlocked skins remain available if your trophy count later drops.
- Health bars are displayed above fighters.
- Practice matches with AI bots that chase, aim, dodge, and dash.
- Mobile joystick and action buttons; desktop WASD/arrow keys, Space to shoot, Shift to dash.
- Trophy progress is saved in the current browser/device.

## Multiplayer status
The friend-room PeerJS feature is experimental and requires a room code. It is not public global matchmaking, does not reliably connect players across all networks, and does not yet support cross-site shared matchmaking or secure server-authoritative ranked progression. Hosting this page on multiple game websites would not automatically make those websites share the same matches; that requires a shared online backend.

## Distribution
The source is public on GitHub. Other game portals require separate submissions and may have their own review, account, and age requirements. This repository has not automatically been published to every game portal.
