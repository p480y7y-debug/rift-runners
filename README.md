# Rift Runners

A free, mobile-friendly browser arena prototype combining:
- **Brawler combat:** blast projectiles, dash, enemy bots, health and knockouts.
- **Social deduction:** one rival is secretly corrupted; get close and interact to expose them.
- **Buildable arena:** spend rift shards to place cover.
- **Objective rounds:** sync terminals, collect shards, and reboot the map.

## Play
Open the hosted game in a modern browser. Desktop: WASD/arrows to move, Space to blast, Shift to dash, E to interact, B to build. Mobile: use the on-screen movement pad and action buttons.

## Run locally
Open `index.html` in a modern browser. No build step or external libraries required.

## Current scope
This is a solo playable prototype against bots, not a full online multiplayer game. It has no account system, matchmaking, server, or user-generated worlds yet. Those need additional backend and moderation work.
